Local variables:
--declared inside a function
--only we can access within a same function
--local var we cannot access outside the function

Global variables:
--declared outside a function ,at the script / module level
--can access anywhere in program(including function)
--can read inside function without any restriction(freely)
--using global keyword we can modify the value of global var from fun definition. and we can call that modified value after function calling.
